# THERVO - Demo Figma Generator Plugin

This native Figma plugin imports and deterministically generates the **100% native, fully editable Figma design file** ("Demo figma") for the **THERVO AI-Driven Sensor-Free Predictive Cooling Dashboard**.

Everything generated by this plugin uses native Figma UI elements:
- Native Figma Frames & Sections
- Master Components with Component Variants
- Figma Design Tokens (Color Variables & Typography Styles)
- Auto Layout containers with flex resizing rules
- Editable Vector Graphics & Canvas Charts (GNN topology nodes & connections)
- Figma Interactive Prototype Connections between all 5 dashboard views

---

## 🚀 Quick Start Instructions (Figma Desktop)

### 1. Requirements
* **Figma Desktop App** (Windows or macOS).
* Internet connection (Figma automatically downloads `Inter` and `Roboto` Google Fonts if not locally available).

### 2. Import the Plugin Manifest
1. Open **Figma Desktop**.
2. Create or open any Figma design draft/file.
3. Click the **Figma Menu** icon (top-left) or right-click the canvas.
4. Navigate to: **Plugins** → **Development** → **Import plugin from manifest...**
5. Select the `manifest.json` file located in this directory:
   `C:\Claude_projects\acm\figma-plugin\manifest.json`

### 3. Run the Plugin
1. Go to **Plugins** → **Development** → **THERVO Demo Figma Generator**.
2. Click to execute.
3. In under 2 seconds, the plugin will create a new page named **"THERVO - Demo Figma"** containing all complete views, design tokens, master components, and prototype links.

## 🎨 Design System & Structure Created

### 1. Design Tokens (Styles)
* **Colors**:
  * `Background/Primary`: `#0a0d14`
  * `Background/Card`: `#111622`
  * `Brand/Cyan`: `#00f2fe`
  * `Brand/Blue`: `#4facfe`
  * `Status/Success`: `#00e676`
  * `Status/Warning`: `#ff9100`
  * `Status/Critical`: `#ff1744`
* **Text Styles**:
  * `Heading/Display`: Inter Bold 28px
  * `Heading/Title`: Inter SemiBold 18px
  * `Body/Medium`: Roboto Regular 14px
  * `Caption`: Roboto Regular 12px

### 2. Master Components & Variants
* **`Master Rack Unit`**:
  * State: `Normal` (Green gradient glow)
  * State: `Warning` (Yellow gradient glow)
  * State: `Critical` (Red pulsing visual indicator)
* **`Navigation Link`**:
  * State: `Default`
  * State: `Active` (Cyan underline & active glow token)
* **`Status Metric Card`**: Reusable metric card with live trend indicators.
* **`Button`**: Reusable action buttons (Primary Cyan, Secondary Dark).
* **`Risk Badge`**: Dynamic status pill badge.

### 3. Dashboard Frames Included
1. **`1. Overview`**: Main THERVO dashboard showing overall data-center health, cooling status, GNN topology canvas, and live telemetry feeds.
2. **`2. Thermal Map`**: Spatial heat map grid with rack surface temperature distributions and airflow vector indicators.
3. **`3. Racks`**: Deep-dive rack unit inspector with per-U temperature distribution, fans RPM, and power draw breakdown.
4. **`4. Predictions`**: AI predictive thermal risk curve, GNN node confidence scores, and automated cooling adjustment recommendations.
5. **`5. Datasets`**: Full benchmark dataset credibility view, validation methodology, sensor-free telemetry specs, and data sources.

### 4. Interactive Prototype Connections
* Every **Navigation Link** component is wired with native Figma prototype click triggers (`ON_CLICK` -> `NAVIGATE_TO` frame) so clicking **Overview**, **Thermal Map**, **Racks**, **Predictions**, or **Datasets** seamlessly switches frames in Figma Presentation mode (`Shift + Space` or `Play`).

## 🛠️ Modifying & Customizing

Since all elements are built with **Auto Layout** and **Figma Native Shapes**:
* You can change colors globally by updating the Color Styles.
* You can adjust font sizes by modifying Typography Styles.
* You can drag and drop rack components to rearrange the data center grid layout seamlessly.
